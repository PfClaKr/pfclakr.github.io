**miniRT**는 42의 레이 트레이싱 과제입니다. 장면 파일을 읽고, 픽셀마다 광선을 쏘고, 맞은 물체를
조명과 그림자까지 넣어 그립니다. OpenGL도 GPU도 없이 C와 `math.h`, 그리고 창에 픽셀을 찍어 줄
MiniLibX만 씁니다. 2인 팀으로 만들었고 보너스까지 모두 해서 **125/100**을 받았습니다
([소스](https://github.com/PfClaKr/Ecole42Paris_miniRT)).

## 장면 파일

```text
A   0.2             255,255,255       # 환경광: 비율, 색
C   0,0,30   0,0,-1   70              # 카메라: 위치, 방향, 시야각
L   0,3,0    1        255,0,0         # 점광원: 위치, 밝기, 색
sp  -10,0,0  5        155,53,152      # 구: 중심, 지름, 색
pl  0,-3,0   0,1,0.2  55,35,172       # 평면: 한 점, 법선, 색
cy  10,0,0   1,1,1    5  5  142,153,45  # 원기둥: 중심, 축, 지름, 높이, 색
```

파싱이 과제의 큰 부분입니다. `A`, `C`, `L`은 정확히 한 번씩 나와야 하고, 모든 벡터는 정규화되어
있거나 정규화할 수 있어야 하며, 비율은 [0, 1], 색은 [0, 255] 범위여야 합니다. 저장소에는 일부러 망가뜨린
장면 파일을 모아 둔 폴더가 있고, 하나하나 크래시 없이 명확한 오류로 거부해야 합니다.

## 픽셀마다 광선 하나

카메라의 위치, 방향, 시야각으로 카메라 앞에 가상 화면을 만듭니다. 화면의 왼쪽 아래 모서리와, 픽셀
하나만큼의 "오른쪽" 벡터와 "위쪽" 벡터를 구해 두면, 픽셀 *(i, j)*의 광선은 이렇게 됩니다.

```c
ray.pos    = cam->pos;
ray.orivec = vunit(cam->left_bottom + i * cam->right_normal
                                    + j * cam->up_normal - cam->pos);
```

광선마다 모든 물체를 검사하고 **가장 가까운** 교점을 남깁니다. 요령은 맞을 때마다 `tmax`를 줄이는
것입니다. 그러면 더 먼 물체는 자동으로 걸러집니다.

```c
while (objects)
{
    hit += hit_sphere/plane/cylinder(objects->data, ray, rec);
    if (hit > 0)
        rec->tmax = rec->t;     // 이제부터는 더 가까운 교점만 받음
    objects = objects->next;
}
```

## 교점은 이차방정식이다

광선 위의 점은 `P(t) = O + tD`입니다. 구는 중심 *C*에서 거리가 *r*인 점들의 집합입니다. 하나를 다른
하나에 대입하면 *t*에 대한 이차방정식이 나옵니다.

```text
(D·D) t² + 2 D·(O − C) t + |O − C|² − r² = 0
```

실근이 없으면 빗나간 것입니다. 아니면 `[tmin, tmax]` 안에 있는 작은 근을 고릅니다. `b` 대신
`half_b = D · (O − C)`를 쓰면 광선마다 곱셈을 몇 번 아낄 수 있습니다.

```c
oc = vminus(ray.pos, sp->pos);
a = vlength2(ray.orivec);
half_b = vdot(oc, ray.orivec);
discriminant = half_b * half_b - a * (vlength2(oc) - sp->radius2);
```

무한히 긴 원기둥도 같은 아이디어인데, 거리를 **축**까지 잽니다. 외적으로 깔끔하게 구할 수 있습니다
(`|(P − C) × 축|`이 *P*에서 축까지의 거리). 그리고 두 가지를 더 확인합니다. 교점이 축을 따라 중심에서
높이의 절반 이내여야 하고, 위아래 뚜껑은 원판이니 반지름으로 제한한 광선–평면 교차로 검사합니다. 평면이
가장 쉽습니다. 나눗셈 한 번, `t = ((P₀ − O) · n) / (D · n)`이면 됩니다.

## 빛과 그림자

교점 *P*와 법선 *N*을 알면 색은 퐁 방식의 모델로 정합니다.

- **환경광**: 물체 색의 일정 비율. 아무것도 완전히 까맣지 않게 합니다.
- **난반사**: 법선과 광원 방향 사이의 코사인인 `max(N · L, 0)`에 비례합니다.
- **정반사**(보너스): `max(R · V, 0)^광택도`에 비례하는 하이라이트. *R*은 광원 방향을 *N*에 대해
  반사한 방향, *V*는 카메라를 향하는 방향입니다.

광원의 기여를 더하기 전에, *P*에서 광원 쪽으로 **그림자 광선**을 쏩니다. 광원보다 가까운 곳에서 무언가에
맞으면 그 광원은 아무것도 기여하지 않습니다.

```c
ray.pos = rec->p;
ray.orivec = vunit(vminus(light->pos, rec->p));
tmp.tmin = EPSILON;
tmp.tmax = vlength(vminus(light->pos, rec->p));
if (hit_object(objects, ray, &tmp))
    return (vec3(0, 0, 0));     // 그림자 안
```

`tmin = EPSILON`이 중요합니다. 이게 없으면 부동소수점 오차 때문에 그림자 광선이 출발한 표면 자체에
맞아서, 모든 물체가 검은 점으로 뒤덮입니다("shadow acne").

## 텍스처 (보너스)

표면에 텍스처를 입히려면 교점마다 [0, 1) 범위의 2D 좌표 *(u, v)*가 필요합니다.

- **구**: 구면 각도, `u = φ / 2π`, `v = θ / π`
- **평면**: 교점을 접선 벡터 두 개에 투영하고 `fmod`로 감쌈
- **원기둥과 원뿔**: 축을 도는 각도가 *u*, 축을 따라간 높이가 *v*

*(u, v)*만 있으면 **체커보드**는 그냥 `(floor(u·k) + floor(v·k)) % 2`입니다. **이미지 텍스처**는 XPM
파일에서 해당 픽셀을 읽습니다. **노멀 맵**은 픽셀마다 방향을 저장합니다. RGB 값을 [0, 255]에서
[−1, 1]로 바꾼 뒤 표면 좌표계(접선, 종접선, 법선)로 회전시키면, 매끈한 구가 울퉁불퉁한 것처럼 음영이
집니다. 지구 장면은 폴리곤 하나 더하지 않고 이렇게 산맥을 얻습니다.

## 개선할 점

- 빛의 감쇠는 손으로 맞춘 선형 곡선입니다. 물리적으로는 세기가 거리의 제곱에 반비례하고, 광원이 여러
  개인 장면에서 그쪽이 더 일관되게 보일 겁니다.
- 모든 광선이 모든 물체를 검사합니다. 경계 볼륨 계층(BVH)을 쓰면 큰 장면이 훨씬 빨라지겠지만,
  512×512 해상도에 물체 수십 개 정도라 필요하지 않았습니다.

miniRT의 가장 좋은 점은 모든 버그가 눈에 보인다는 것입니다. 부호가 틀리면 구가 뒤집히고, epsilon이
빠지면 여드름이 나고, 법선이 틀리면 검은 줄이 생깁니다. 선형대수를 이렇게 쉽게 디버깅해 본 적이 없습니다.
